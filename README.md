# 📜 노인일자리 실외사업단 비대면 교육 이수확인증 도구

> **노인복지관 실무 담당자와 어르신 참여자를 위한 비대면 교육 이수확인 및 공식 양식(PDF) 자동 발급 웹 도구**  
> `공원환경개선`, `지역사회환경개선` 등 실외사업단 어르신들이 모바일에서 간편하게 본인 확인 후 비대면 교육 이수 서약 및 정자 서명을 제출하고, 담당자는 하루 정확히 3시간 교육 배정 및 공식 서식 PDF를 즉시 생성·일괄(ZIP) 다운로드할 수 있습니다.

---

## 📌 1. 주요 특징 및 핵심 원칙

1. **설치 불필요, 단일 웹 도구 (`index.html`)**:
   - 별도 서버나 Node.js 설치 없이 브라우저(Chrome, Edge, Safari, 모바일 브라우저)에서 더블 클릭만으로 즉시 작동합니다.
   - 네트워크 연결 여부와 상관없이 로컬 브라우저 영속 저장(`localStorage`)을 지원합니다.
2. **2026년 공식 원본 서식 탑재**:
   - 수행기관 공식 양식 `(양식)+2026년+이수확인증_수정.pdf` 서식이 내장되어 있어 기관명, 사업단명, 생년월일, 성명, 배정일, 실제 정자 서명이 정밀한 좌표에 오버레이되어 완벽한 공식 문서로 출력됩니다.
3. **하루 정확히 3시간 배정 검증 (PRD 규칙 엄격 적용)**:
   - 2시간 또는 4시간 배정은 저장이 차단되며, **정확히 3시간 조합(1h+1h+1h, 2h+1h, 3h 단독 등)**만 저장됩니다.
4. **고령 참여자 친화적 디자인**:
   - 큰 글씨, 고대비, 단계별 쉬운 안내, 모바일 터치 손가락 서명 패드, 부정 이수 방지 서약문 강조.
5. **개인정보 보호 및 공용 단말기 배려**:
   - 주민등록번호 미수집 (`이름 + 생년월일` 대조).
   - 접속 URL에 개인정보 미노출.
   - 복지관 공용 스마트폰 사용 후 "개인정보 정리 및 다음 참여자 로그인" 기능 제공.

## 🚀 3. 사용자별 이용 방법

### 👵 [참여자(어르신) 모드]
1. **어르신 본인 확인**:
   - 성함(예: `김순자`)과 생년월일 6자리(`520315`) 또는 8자리(`19520315`) 입력.
2. **배정된 교육 확인**:
   - 미제출 교육 배정일 중 가장 오래된 날짜부터 자동 표시됩니다.
   - 부정 이수 방지 경고문을 확인합니다.
3. **과목별 이수 확인 & 정자 서명**:
   - 각 배정 과목(하루 총 3시간)마다 "이수 확인" 체크박스를 누르고, 서명 패드에 손가락으로 이름을 정자로 서명합니다.
   - 일부 과목만 작성하고 나가도 저장되어, 재접속 시 남은 과목을 이어서 진행할 수 있습니다.
4. **최종 제출**:
   - 모든 과목 체크와 서명 완료 시 [오늘 교육 이수확인증 최종 제출하기]를 누르면 실시간 시각(KST)으로 기록되며 제출이 완료됩니다.

---

### 👨‍💼 [담당자 관리 모드]
- 우측 상단 **[담당자 관리]** 탭 클릭 후 비밀번호 입력 (초기 비밀번호: `admin1234`).

1. **이수 현황 및 발급**:
   - 실시간 진행 상태(미제출 / 일부완료 / 제출완료) 조회 및 성함/사업단별 필터링.
   - [이수확인증 PDF 다운로드]: 참여자별 공식 확인증 1장 즉시 생성.
   - [선택 확인증 일괄 다운로드 (ZIP)]: 여러 명의 확인증을 하나의 압축파일로 다운로드.
   - [담당자 검토 확인]: 서명 확인 후 승인 처리.
2. **교육 배정 관리**:
   - 사업단 전체 일괄 배정 또는 특정 참여자 개별 배정.
   - 17개 과목 중 선택 시 실시간 시간 합산 (정확히 3시간일 때만 저장 활성화).
   - 기존 배정 내역 조회 및 삭제.
3. **참여자 명단 관리**:
   - 신규 참여자 수동 추가.
   - **엑셀 일괄 등록 (`.xlsx`)**: 엑셀 파일을 드래그 앤 드롭하여 대량 등록 (중복 행 자동 감지).
   - **표준 엑셀 서식 다운로드** 버튼 제공.
4. **설정 및 백업**:
   - 기관명(복지관명), 실외사업단 명칭, 관리자 비밀번호 변경.
   - **가상 실외사업단 샘플 로드**: 테스트용 10명 참여자 및 3시간 배정 샘플 원클릭 생성.
   - **데이터 JSON 백업 및 복원**: PC 교체나 데이터 보관용 백업 파일 내보내기/불러오기.

## ✅ 5. PRD 검증 시나리오 충족 여부

1. ✅ **올바른 엑셀에서 참여자·사업단 등록 & 중복 행 표시**: SheetJS 연동 및 중복(`이름+생년월일`) 검출 완료.
2. ✅ **사업단 일괄 배정 후 특정 참여자 과목 개별 변경**: 사업단 일괄 배정 및 개별 배정 분리 지원.
3. ✅ **엄격한 3시간 배정 검증**: 2시간, 4시간 배정 저장 차단, 정확히 3시간만 저장.
4. ✅ **참여자 이름·생년월일 대조 & 타인 정보 조회 차단**: 단일 본인 매칭 시에만 본인 배정 노출.
5. ✅ **가장 오래된 미제출 교육부터 자동 표시**: 날짜순 자동 정렬 및 미완료 우선 배정 표시.
6. ✅ **체크 및 서명 필수 검증**: 누락 과목 존재 시 제출 불가 안내.
7. ✅ **이어하기 지원**: 과목별 서명 상태 보존 및 재접속 시 잔여 과목 이어하기.
8. ✅ **실제학습일에 배정일 자동 입력 & 실제 제출시각 별도 기록**: KST 기준 타임스탬프 기록.
9. ✅ **하루 3시간 완료 시 공식 PDF 1장 자동 발급**: 원본 서식과 17과목 그리드 좌표 완벽 매핑.
10. ✅ **담당자 비밀번호 인증**: 미인증 상태에서 관리자 화면 접근 차단.
11. ✅ **개인 PDF 및 일괄 ZIP 다운로드**: `pdf-lib` + `jszip` 기반 무설치 완벽 지원.
